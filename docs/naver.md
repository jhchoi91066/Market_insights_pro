# 네이버 API를 활용한 웹 크롤링 및 데이터 분석 요약

제공된 글은 **네이버 쇼핑 API를 활용하여 '아이패드' 상품 데이터를 합법적으로 수집(크롤링)하고, 수집된 데이터를 분석 및 시각화하는 과정**을 상세히 설명합니다.

---

## 주요 내용 요약

### 1. 네이버 API 준비
* **API 등록:** 네이버 개발자 센터에서 Open API 이용을 신청하고, **`Client ID`**와 **`Client Secret`**을 발급받습니다. 이는 API 요청 시 인증을 위해 필요합니다.

### 2. 웹 크롤링 자동화
* **기본 요청:** `urllib` 라이브러리를 사용하여 특정 검색어('맥북')에 대한 쇼핑 검색 결과를 JSON 형태로 받아오는 기본 코드를 작성합니다.
* **함수화 및 자동화:** 한 페이지만 가져오는 것을 넘어 여러 페이지의 데이터를 자동으로 수집하기 위해 과정을 함수로 만듭니다.
    * `gen_search_url()`: 검색어, 시작 페이지 번호, 한 페이지에 표시할 개수 등을 조합하여 요청 URL을 생성하는 함수.
    * `get_result_onpage()`: 생성된 URL과 인증 정보를 담아 네이버 서버에 데이터를 요청하고 JSON 응답을 받는 함수.
    * `get_fields()`: JSON 데이터에서 '상품명', '최저가', '판매처', '링크' 등 필요한 정보만 추출하고, `<b>` 같은 불필요한 HTML 태그를 제거하여 Pandas DataFrame으로 변환하는 함수.
* **대량 데이터 수집:** `for` 반복문을 사용하여 위 함수들을 실행, '아이패드' 검색 결과 1000개를 100개씩 10번에 걸쳐 자동으로 수집하고 하나의 데이터프레임으로 합칩니다.

### 3. 데이터 전처리
* **데이터 확인:** 수집된 데이터의 정보를 `.info()`로 확인합니다.
* **타입 변환:** 가격(`lprice`) 데이터가 숫자(float)가 아닌 문자열(object)로 저장된 것을 발견하고, 분석을 위해 숫자 타입으로 변환합니다.

### 4. 데이터 분석 및 시각화
* **기초 통계 분석:**
    * `.describe()` 함수를 사용하여 가격 데이터의 평균(약 83만 원), 최솟값(1원), 최댓값(890만 원) 등 기초 통계치를 확인합니다.
    * 최댓값인 890만 원짜리 상품이 실제로 옥션에서 판매 중임을 링크를 통해 확인합니다.
* **데이터 시각화:**
    * **막대그래프 (Bar Chart):** 어떤 판매처(mall)가 가장 많은 상품을 등록했는지 시각화하여 보여줍니다. (G마켓, 옥션, 인터파크쇼핑 순)
    * **박스플롯 (Boxplot):** 가격의 전체적인 분포, 중앙값, 사분위수 범위를 시각적으로 파악하고, 정상 범위를 크게 벗어나는 '이상치(Outlier)' 데이터를 확인합니다.

---

> **결론:** 이 글은 파이썬과 네이버 API를 이용해 웹 크롤링을 수행하고, `Pandas`와 `Matplotlib` 같은 라이브러리로 데이터를 가공, 분석, 시각화하는 전 과정을 보여주는 실용적인 가이드입니다.
